For UCOS Ω∞, Constitutional Laws and Constitutional Invariants are not the same thing.
1. Constitutional Laws
A Constitutional Law is a governing rule that defines how the system must behave.
Laws can create obligations, constraints, permissions, prohibitions, and governance requirements.
Laws may evolve through constitutional evolution mechanisms.
Structure
LAW

├── Law ID
├── Name
├── Purpose
├── Scope
├── Statement
├── Rationale
├── Enforcement
├── Exceptions
├── Evidence Requirements
├── Certification Rules
└── Evolution Rules
Example
LAW-001

Knowledge Once Principle

A canonical fact shall be authored once
and referenced everywhere else.

Duplicate canonical ownership is prohibited.
2. Constitutional Invariants
An Invariant is stronger than a Law.
An Invariant is a condition that must always be true.
If an invariant becomes false:
System Integrity = Broken
A law can be violated.
An invariant cannot be violated.
Violation means:
Constitutional Failure
Example
Invariant:

Every Canonical Object
has exactly one Canonical Owner.
If two owners exist:
Invariant Failure
The platform is constitutionally inconsistent.
Mathematical View
Law
IF condition
THEN behavior
Example:
IF artifact changes
THEN certification required
Invariant
Always True
Example:
Artifact ID is globally unique.
No exceptions.
